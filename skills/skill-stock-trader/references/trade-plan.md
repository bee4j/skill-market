# 止盈止损、仓位与买卖点的量化规则

所有价位都必须能倒推到一个可复述的规则。禁止出现「感觉会涨到…」「大概支撑在…」这类无依据表述。

## 一、买入价怎么定

先定买入方式，再定具体价格：

| 方式 | 触发条件 | 挂单价 |
|---|---|---|
| 突破买 | 放量突破前高或箱体上沿，量能较 5 日均量放大 1.5 倍以上 | 突破日收盘价上方 0–1%；**追高不超过 3%** |
| 回踩买 | 上升趋势中缩量回调至 5 日或 10 日线 | 均线附近（±1%），或前高转支撑位 |
| 低吸买 | 长期下跌后横盘，首次放量向上 | 突破当日不看回踩，次日回踩不破突破位再买 |

**分仓路径**（不要一把梭）：

- 首笔试错仓：目标仓位的 50%
- 走势符合预期（收盘站稳买入价、量能维持）：补到目标仓位
- 走势不符（3 个交易日内跌破买入价且无量收回）：不再补仓

## 二、止损：三个维度取最先触发者

| 维度 | 规则 |
|---|---|
| 价格止损 | 收盘跌破近 20 日低点；或收盘跌破 20 日均线（强趋势票用 5 日或 10 日线）。**必须写明是收盘确认还是盘中破位** |
| 幅度止损 | 默认 -6%。按波动率调整：日均振幅 >5% 用 -8%，3%–5% 用 -6%，<3% 用 -5% |
| 时间止损 | 短线 5–10 个交易日未按预期方向突破；中线 1–2 个月横盘未启动 |

**确认方式**：盘中瞬时插针跌破不算触发，收盘破位才算；连续两个交易日收在关键位下方，视为有效破位。

**触发后动作顺序**（这是纪律的核心）：

1. 触发即执行，不在触发后重新评估持有理由——评估应在建仓前完成。
2. 一次性退出，或先减半、次日不能收回再清 —— 二选一，建仓时就定好，不要临场改。
3. 禁止「再等等说不定回来」的自我合理化。

## 三、止盈：三档 + 移动止盈

| 档位 | 位置 | 动作 |
|---|---|---|
| T1 第一目标 | 最近的前高，或密集成交区上沿 | 减 1/3 |
| T2 第二目标 | 量度升幅：突破点 + 箱体或平台高度 | 再减 1/3 |
| T3 情绪止盈 | 换手率 >15% 且放量滞涨，或出现长上影 | 清剩余 |
| 移动止盈 | 浮盈 >15% | 止损上移至成本线 |
| | 浮盈 >25% | 改用 10 日均线跟随 |
| | 浮盈 >40% | 改用 5 日均线跟随 |

目标价到达不等于必须卖：若当日强势放量穿越且板块同步走强，可上调 T1 至下一阻力位，但必须重新给出该阻力位的具体价位。

## 四、盈亏比门槛（硬性）

```
盈亏比 = (T1 目标价 − 买入价) / (买入价 − 止损价)
```

- **≥ 2:1 才可建仓**。
- 1.5–2:1 之间：只能小仓位试错，且必须说明「盈亏比不足，仅试错」。
- < 1.5:1：明确写「不做」，并说明是目标空间不够还是止损位太远。**不要为了凑出建议而放宽止损。**

## 五、仓位

### 按大盘档位定总仓位

| 大盘档位 | 总仓位上限 | 单票上限 |
|---|---|---|
| 进攻 | 70%–80% | 20% |
| 震荡 | 40%–60% | 15% |
| 防守 | ≤30% | 10% |
| 切换 | ≤30%，只减不加 | 10% |

### 按位置定操作

| 位置 | 允许的操作 | 建议仓位 |
|---|---|---|
| 低位启动 | 试错仓介入，确认后加 | 首笔 5%–10% |
| 趋势中继 | 回调加仓，最优位置 | 10%–15% |
| 高位加速 | 只减不加 | 持有者减 1/3 以上 |
| 高位震荡 | 观望或减仓 | 不新增 |
| 下跌反抽 | 不参与 | 0 |

**环境不支持时敢直说不执行**。大盘防守档 + 个股高位加速，即使个股形态好看也应放弃。

## 六、失效条件（每只标的必写）

以下任一条成立，即降仓或退出：

- **逻辑证伪**：核心催化落空、公告澄清、业绩不及预期
- **板块转弱**：板块龙头跌停，或板块单日跌幅 >5%
- **放量破位**：量能放大 1.5 倍以上且跌破关键位
- **次日负反馈**：该强不强，高开低走收阴

失效条件不是「风险提示」，是**判断错了的证明标准**。写不出来就说明这笔交易没有可验证的前提，应放弃。

## 七、持仓脱锚（用户报成本价时）

用户说「我成本 35 元套了 40% 怎么办」时，第一步不是算解套位，而是脱锚：

- 成本价是用户的心理锚，**不影响标的当前该不该持有**。
- 正确顺序：① 基本面有没有破坏 → ② 走势处于什么位置 → ③ 原买入逻辑还在不在 → ④ 再进入止损框架。
- 典型话术：「先放下成本价。35 元是你的买入价，不影响它现在该不该持有。我们分别看基本面、走势位置、原逻辑这三点，再决定是止损还是继续持。」

**浮盈被打回成本不是止损的理由**，两者退出原因不同，不要说混。
